# Exception-Handling-Library-OPP
"C++ Exception Handling Library with 9+ custom exception types"

This project is a **menu-driven C++ application** that demonstrates
**custom exception handling** using **Object-Oriented Programming (OOP)** and **templates**.

It is developed as an **academic project** for **Programming Fundamentals / Object Oriented Programming**.

---

## Features / Exceptions Implemented

* User Interruption Exception (SIGINT)
* Overflow & Underflow Exception
* Division by Zero Exception
* Invalid Input Exception
* File Handling Exceptions

  * File existence check
  * File append check
  * File write / create check
* Index Out of Bound Exception
* Null Pointer Exception
* Data Conversion Exception (Hexadecimal & Octal)
* Default Exception

## ▶️ How to Run

1. Open the project in **Dev C++ / CodeBlocks / Visual Studio**
2. Compile `main.cpp`
3. Run the program
4. Choose an exception type from the menu

> ⚠️ **Note:** This project is **Windows-based** and uses `windows.h`, `Sleep()`, and `system("cls")`.
